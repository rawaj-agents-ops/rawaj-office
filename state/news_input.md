1. Put today's date in Cairo on the DATE line, as YYYY-MM-DD. If it does not match the run date, the run sends no report and spends no model quota.
2. One block per item, in the order you want them considered.
3. Only what the source actually says. If a number or a claim is not in the source, leave it out or mark it unclear.
4. Nothing is published automatically. The team writes drafts; the founder posts from his own accounts.
